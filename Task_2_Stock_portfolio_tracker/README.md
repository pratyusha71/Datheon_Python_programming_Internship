# Stock Portfolio Performance Tracker

## Project Description
The Stock Portfolio Performance Tracker is a Python-based
application designed to help users monitor their stock
investments and calculate portfolio performance.

## Features
- Load S&P 500 stock ticker dataset using CSV.
- Validate stock ticker symbols.
- Accept stock purchase details.
- Calculate total investment.
- Calculate current portfolio value.
- Calculate profit and loss.
- Calculate percentage gain or loss.
- Generate portfolio summary.
- Export portfolio results into a CSV file.

## Technologies Used
- Python 3
- CSV Module
- File Handling
- Dictionaries
- Exception Handling

## Project Structure

Task_2_Stock_Portfolio_Tracker/

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run portfolio.py.
4. Enter the stock ticker symbol.
5. Enter purchase price and number of shares.
6. Enter the current stock price.
7. View the portfolio summary.
