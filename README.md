## 🚀 Projects

### 🎮 Task 1 – Hangman Word Guessing Game

A fun and interactive command-line game developed using Python, where players attempt to guess a hidden word within a limited number of attempts.

**Highlights:**
- Random word selection.
- Interactive user input.
- Limited guessing attempts.
- Hangman visual representation.
- Win and lose conditions.

**Technology:** Python

---

### 📊 Task 2 – Stock Portfolio Performance Tracker

A Python-based application designed to track stock portfolio information and analyze investment performance.

**Highlights:**
- Portfolio data management.
- CSV file handling.
- Stock information processing.
- Portfolio performance calculations.
- Organized output and reporting.

**Technology:** Python, CSV

---

### 📂 Task 3 – Automated File Organizer & Cleanup Utility

A desktop automation utility that organizes cluttered directories by identifying file extensions and automatically sorting files into appropriate folders.

**Highlights:**
- Automatic file identification.
- Dynamic folder creation.
- File categorization.
- Duplicate filename handling.
- Permission and exception handling.
- Preview mode before organizing.
- Execution summary.
- File restoration utility.

**Technologies:** Python, OS, Shutil, Pathlib, Logging
