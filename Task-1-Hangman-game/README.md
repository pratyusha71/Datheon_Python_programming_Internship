HANGMAN WORD GUESSING GAME

PROJECT DESCRIPTION:
This is a Python-based console Hangman game in which the computer randomly selects a secret word. The player must guess the word one letter at a time before running out of attempts.

FEATURES:
1. Random word selection.
2. Hidden word displayed using underscores.
3. Maximum of 6 incorrect attempts.
4. ASCII Hangman drawings.
5. Tracks previously guessed letters.
6. Prevents repeated guesses.
7. Displays victory and defeat messages.

TECHNOLOGIES USED:
- Python
- Random module
- VS Code

HOW TO RUN:
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute: python hangman.py

GAME RULES:
- Guess one letter at a time.
- Correct guesses reveal the letters.
- Incorrect guesses reduce your attempts.
- You have 6 incorrect attempts.
- Guess the complete word to win!

PROJECT TYPE:
Console-Based Python Application.
